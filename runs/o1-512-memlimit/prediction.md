# O1 512 MiB 同负载成本补测：测前预测

两轮均设 MemoryMax=512M、MemorySwapMax=0、GOGC=100，不限制报表并发；按同一 10/20/30 请求每秒曲线运行，每阶段 60 秒。仅改变 GOMEMLIMIT：对照组 off，实验组 170MiB。

依据 A3 的 512 MiB 校准结果，预计两组在 10、20 请求/秒阶段都能存活，从而获得同负载的 GC 与 CPU 对照。170MiB 软限制可能在 20、30 请求/秒时增加 GC 频率和 GC CPU 速率、降低 RSS，但不能保证 30 请求/秒不会 OOM；CPU 总速率的变化还包含业务工作。只比较两组都存活并完成采样的同一阶段；若某阶段发生 OOM，记录为不可比。
